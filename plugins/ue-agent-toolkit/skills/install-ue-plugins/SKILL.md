# Install UE Plugins

Install the bundled source-only Unreal plugins into the target project's `Plugins/` directory. Preserve existing project files and require explicit approval before replacing a conflicting plugin.

## Workflow

1. Resolve the target project root.

Use the directory containing the target `.uproject`. Do not install into the Codex plugin cache or toolkit source repository unless that directory is itself the intended Unreal project.

2. Resolve the installer.

Use `scripts/install_plugins.py` beside this `SKILL.md`. It discovers plugin payloads under `assets/Plugins/`; the current bundle contains `UnrealMCPToolsets`.

3. Preview the installation.

Run:

```shell
py -3 "<skill-directory>\scripts\install_plugins.py" --project-root "<unreal-project-root>" --dry-run
```

If the machine exposes Python as `python3` instead of `py -3`, use that launcher.

4. Handle conflicts safely.

- If a destination is missing or identical, continue.
- Ignore generated `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`, and `.vs/` directories when comparing an installed plugin with the bundled source.
- If the preview reports a conflict, show the plugin names and stop for explicit replacement approval.
- Never use `--force` based on an assumption.
- An approved replacement backs up the complete existing plugin under `<project>/.ue-agent-toolkit/backups/unreal-plugins/` before synchronizing the bundled source files. Generated build directories remain in place and are regenerated by the subsequent editor-target build.

5. Install the plugins.

Run the same command without `--dry-run`. Add `--force` only after the user explicitly approves replacing every reported conflict.

6. Verify and report.

Confirm `<unreal-project-root>/Plugins/UnrealMCPToolsets/UnrealMCPToolsets.uplugin` exists. Report installed, unchanged, and replaced plugins separately, and include every backup path.

Do not edit the project's `.uproject` or enable plugins automatically. Tell the user that `UnrealMCPToolsets` requires Unreal Engine 5.8 and the engine `ToolsetRegistry` plugin, then ask them to enable it and rebuild the editor target. Do not launch Unreal Editor or start a build unless the user also requested that action.
